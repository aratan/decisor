El modelo decide: batalla naval

En un tablero de 5×5 hay un barco de 3 casillas oculto. Cada turno el modelo de Ollama recibe el estado y devuelve la probabilidad de acertar en cada casilla libre; tú ves el mapa de calor y la casilla elegida. Nadie escribe el disparo.

Conexión
  • ¿Está Ollama en marcha? Arráncalo con ollama serve.
  • ¿Tienes el modelo instalado? ollama pull nimble (solo modelos Nimble o Tev aceptan /v1/systemone).
  • ¿Falta CORS? El navegador exige permiso de origen: reinicia Ollama con OLLAMA_ORIGINS=* ollama serve (o limita el origen, p. ej. OLLAMA_ORIGINS=http://localhost:8000).
  • Sirve la demo desde localhost: ./demo/run.sh desde la raíz del repo (o python3 -m http.server y abre http://localhost:8000/demo/batalla.html). Desde file:// el origen null suele ser rechazado.

El estado que recibe el modelo es un JSON pequeño ({mapa, impactos, disparos}) con la rejilla en ASCII (X=impacto, .=fallo, ?=sin disparar); la pregunta se llama casilla y es de tipo choice con una criteria por casilla libre. La página debe servirse desde localhost (./demo/run.sh, o python3 -m http.server en la raíz del repo) porque el navegador llama directamente a POST /v1/systemone de Ollama y necesita CORS.
